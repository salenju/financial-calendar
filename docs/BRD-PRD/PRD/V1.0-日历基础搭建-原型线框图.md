# V1.0-金融日历-原型线框图

> 配套文档：[V1.0-日历基础搭建-PRD](./V1.0-日历基础搭建-PRD.md)
> 说明：本文为**低保真线框图（Wireframe）**，用于确认信息结构与交互流程，不含视觉风格。所有尺寸均为相对示意。

---

## 0. 设计前提

| 项 | 约定 |
| --- | --- |
| 交付形态 | Web Component SDK，可嵌入；另附独立访问页面 |
| 自适应基准 | 按**宿主容器宽度**自适应，而非 viewport（PC ≥ 768px，H5 < 768px） |
| 状态色 | 🟢 正常 `#52C41A`　🟡 部分延迟 `#FAAD14`　🔴 高风险 `#F5222D`　⚪ 无数据 `#BFBFBF`　★ 大促（金色） |
| 周末 | 浅灰背景，不作为风险色 |

---

## 1. 信息架构

```
独立页面 / 宿主嵌入
├─ P4 倒计时 Widget（首页入口）
└─ P1 日历主视图
    ├─ P2 日期详情（PC 右侧栏 / H5 底部弹层）
    ├─ P5 币种订阅设置（居中弹层）
    └─ P3 近期动态列表
        ├─ 假期详情
        └─ 大促详情（含前置节点）
```

**交互标注**

| 编号 | 元素 | 行为 |
| --- | --- | --- |
| ① | 月份切换 ← → | 切换月份，重新拉取并渲染 |
| ② | 状态点 | 悬停显示当日简要 Tooltip |
| ③ | 某一天（含大促日） | 点击 → 右侧面板更新为当日详情 |
| ④ | 搜索币种 | 输入即筛选日历显示范围 |
| ⑤ | 常用币种按钮 | 打开 P5 币种订阅弹层 |
| ⑥ | 近期动态条目 | 点击 → 定位到日历对应日期并打开详情 |
| ⑦ | 查看大促详情 | 打开大促详情浮层（见 5 节） |

## 11. 组件规格速查

| 组件 | 尺寸（示意） | 关键约束 |
| --- | --- | --- |
| 日历单元格 | 正方形，最小 44×44px（H5 触控友好） | 可同时承载状态点 + 大促标识 |
| 状态点 | 6–8px 圆点 | 大促用星标，与状态点区分 |
| 日期详情（PC） | 宽 320px 右侧栏 | 随日历区高度自适应 |
| 日期详情（H5） | 底部弹层，高 ≤ 70% 屏 | 支持拖拽关闭 |
| Widget | 高 56–72px | 可自适应宿主宽度 |
| 弹层遮罩 | rgba(0,0,0,0.45) | 点击可关闭 |
