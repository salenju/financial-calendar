# V1.0-日历基础搭建-BRD

## 需求背景
作为跨境电商卖家我想清楚的知道每个银行的假期情况，以便在做跨境支付时及时了解各银行假期情况，避免在跨境支付中出现不可抗力因素，导致跨境支付失败。
对于跨境支付用户来说，“时间就是金钱”，资金晚到一天可能导致供应商断货、错过平台大促或产生汇率损失。因此，这个金融日历不只是一个“查日期的工具”，更应该是一个“资金流转风险管理与备货规划助手”。

## 需求描述
金融日历：我想做一款金融日历的小工具给用户使用，主要想：
1.帮助用户在做跨境支付过程中及时了解各银行假期情况
2.重要促销活动的具体日期
3.距离重要促销活动的 倒计时提醒等

## 需求分析

### 核心要求
- 支持在EOS管理系统配置日历展示所需数据（可后续迭代，V0.1可以不实现，但是技术设计时需要支持）
- 日历作为小工具希望做成SDK形式，方便集成到其他系统中
- 日历要支持PC和H5端

### 核心痛点分析
- **信息碎片化且不对称**：各国节假日极多（如越南春节、沙特周末），用户根本记不住，也不知道对“收款/付款”到底有没有影响。
- **资金链断裂风险**：银行假期导致提款延迟，用户如果没提前准备，容易造成信用卡还款逾期或供应商付款违约。
- **错失营销良机**：跨境电商（如黑五、Prime Day、斋月）需要提前备货和结汇，错过时间点就错过了一整年的业绩。

### 具体落地与优化方案（对应你的3个需求）

#### 1. 帮助用户及时了解各银行假期情况（核心：强关联“业务影响”）
从你的图1来看，现在的做法是列举“币种+假期+延迟说明”。这很好，但可以更智能。
*   **带业务标签的分类视图**：
    *   不要只显示“美元假期”，而是按“收汇影响”、“付汇影响”分类。
    *   **明确高亮**：像图1中“人民币不受假期影响...独家闪速到账”就是极好的痛点安抚，建议用绿色高亮框展示。
*   **时区与“截止时间”（Cut-off Time）换算**：这是支付工具最核心的痛点。不要只显示“某日是假期”，必须提示**“北京时间X月X日14:00前提交，可当天处理，否则顺延至下一个工作日”**。
*   **个性化订阅**：允许用户根据自己店铺的经营范围，勾选“我常用的币种”（如美元、欧元、越南盾）。首页只展示用户关联的币种，避免信息过载。
*   **颜色区分日历（UI优化）**：图2中的日历目前是蓝点，建议引入“红黄绿”预警机制：
    *   绿点：正常结算。
    *   黄点：部分地区延迟（如越南假期）。
    *   红点：全面停滞/双休日。
    *   点击某一天，直观展示“受影响币种”和“解决方案（如换用人民币直采）”。

#### 2. 重要促销活动的具体日期（核心：绑定“备货与资金节点”）
跨境电商的促销活动是资金流转的高峰期，日历必须与电商节奏结合。
*   **平台大促日历**：内置Amazon Prime Day、黑五网一、双11、斋月（Ramadan）、感恩节等。
*   **关联资金建议**：在活动日期前添加“资金倒计时节点”。例如：黑五前30天，标记“建议开始换汇备货”；黑五前7天，标记“物流截单日”。
*   **本地化节日**：不仅是欧美节日，也要涵盖目标市场本土节日（如东南亚的斋月、拉美的狂欢节），因为这些节日会直接影响当地物流和海关的清关速度。
*   **提供宏观数据辅助**：在促销日旁边，可以附带“预计汇率波动提示”或“建议结汇窗口期”，把日历变成决策工具。

#### 3. 距离重要促销活动的倒计时提醒（核心：主动触达，防患未然）
用户不会每天主动打开日历看，所以**主动提醒（Push）**是关键。
*   **首页倒计时小组件（Widget）**：在App首页或小工具界面，直接显示“距离黑五还有 15 天 | 建议提前结汇”。
*   **智能预警推送（防资金断链）**：
    *   **长假期预警**：提前7天/3天推送。“美国独立日假期即将来临（7月4日），美元提款将延迟1个工作日，建议您提前安排资金。”
    *   **大促前置提醒**：根据用户的交易习惯，在特定大促前15天推送：“黑五临近，近期换汇需求增加，建议您尽早锁定汇率并安排提款。”
*   **可操作的提醒（Actionable Alerts）**：推送不要只说“有假期”，要附带按钮，如【立即提款】、【查看换汇策略】、【联系客服】。

### 基于你现有截图的 UI/UX 具体改进建议

1. **顶部快捷搜索/过滤（图1）**：图1左侧有个“全部币种”的输入框，这很好。建议增加“只看我的常用币种”开关。
2. **近期动态聚合（图2）**：图2底部的“近期动态”排版不错，但目前像是流水账。建议改成卡片式，分为“⚠️ 延迟预警”和“🎉 促销活动”两类。
3. **场景化文案优化**：
    *   原：*“是越南假期，有关地区入账延迟，出款至对应地区的打款也会有所延迟”*
    *   优化：*“受越南假期影响，越南盾入账将延迟1-2个工作日。建议您提前安排货款结算，或使用人民币直采通道规避影响。”*（给出解决方案）
4. **双向交互日历**：点击日历上的某一天，不仅能看放假通知，还能显示当天的“汇率参考”和“历史延迟发生率”。

### 💡 进阶加分项（增值服务）
*   **汇率日历**：结合历史数据，提示用户“每月初/月末”通常是汇率波动较大且跨境支付拥挤的节点。
*   **智能路由建议**：当检测到用户要提现的币种正在假期时，自动推荐替代方案（例如：美元假期，推荐使用人民币CNY直采到1688，无缝衔接）。

**落地步骤建议（MVP规划）：**
*   **V1.0（基础版）**：做好多币种假期查询，实现红黄绿状态标记，加上硬编码的电商大促日期。
*   **V2.0（智能版）**：加入Push倒计时提醒，根据用户历史交易币种做个性化推送。
*   **V3.0（生态版）**：深度结合你的支付/结汇功能，在日历上直接实现“一键预约提款”、“提前锁汇”。
